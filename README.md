### OdontoSoft

Prototipo frontend de gestión odontológica con directorio de pacientes, expedientes, registro de citas y odontograma SVG con historial por pieza dental.

- Tecnologías verificadas: Next.js, React, TypeScript, MUI y Redux Toolkit.

- Utiliza datos ficticios en memoria; los cambios se reinician al recargar. La conexión a la base de datos y la autenticación real están pendientes.
- [Consultar el código](https://github.com/RogerG03/odonto-soft) (repositorio privado: requiere permiso).

## Abrir el portafolio

1. Descarga este repositorio desde **Code → Download ZIP** y extrae su contenido.
2. Abre `index.html` con Chrome, Edge o Firefox.
3. Conserva `styles.css` en la misma carpeta.

No se requieren dependencias ni servidor. Esta entrega está implementada con HTML y CSS; las tecnologías React y Next.js corresponden a los proyectos presentados.
