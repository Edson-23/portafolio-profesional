Restaurant Don Pepe

La atención y la cocina en una interfaz modular.

Aplicación con vistas diferenciadas para meseros y cocina. El código organiza la atención por mesas, el manejo de órdenes y la consulta de recetas en módulos separados.

  • Componentes para mesas, platillos y órdenes.
  • Estado de mesas y órdenes organizado con Redux.
  • React
  • JavaScript
  • Vite
  • Redux Toolkit
  • CSS
