OPERACIÓN DE RESTAURANTE

Restaurant Don Pepe

La atención y la cocina en una interfaz modular.

Proyecto de graduación para la gestión de pedidos del Restaurante Rancho Don Pepe. La interfaz separa las vistas de meseros y cocina, con componentes para mesas, órdenes y recetas.

Mi participación: desarrollo frontend con React, diseño adaptable, análisis del flujo de pedidos, documentación técnica y control de versiones, según mi CV. Mayo–octubre de 2025.

  • Navegación entre paneles de meseros y cocina.
  • Componentes para mesas, platillos y órdenes.
  • Estado de mesas y órdenes organizado con Redux.
  • React
  • JavaScript
  • Vite
  • Redux Toolkit
  • CSS

Alcance revisado: estructura y componentes del frontend. El repositorio también incluye un backend Django; no se ha verificado su integración en ejecución.

GESTIÓN ODONTOLÓGICA

OdontoSoft

Información clínica organizada, desde el frontend.

Prototipo frontend para explorar la gestión de pacientes y expedientes odontológicos. Integra un directorio, el registro de citas y un odontograma SVG con historial por pieza dental.

  • Búsqueda y filtros en el directorio de pacientes.
  • Expedientes con registro de citas e historial dental.
  • Odontograma interactivo con diferentes denticiones.
  • Next.js
  • React
  • TypeScript
  • MUI
  • Redux Toolkit

Demostración con datos ficticios en memoria. Los cambios se reinician al recargar; la autenticación real y la conexión a una base de datos están pendientes.
